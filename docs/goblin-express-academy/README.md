# Goblin Express Academy

*We Deliver. Mostly.*

A course for game developers who want to build real games with AI. Learners spend 12 weeks building one shared game, a goblin courier delivery game called Goblin Express, with Claude Code: first in the browser (2D with PixiJS, then 3D with Three.js), then in Godot, Unity or Unreal. It is the Learn section of gamesandai.org.
