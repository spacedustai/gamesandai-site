# Course overview

## Audience

Working game developers, whether programmers or artists, who know how games are made but have little or no experience building with AI agents. Many are on Windows and are not command-line users. They are skeptical and busy, so the course has to deliver a real result fast.

## Goal

Get learners from "interested but inexperienced with AI" to building games with AI that can go into production. The focus is Claude Code, in the terminal and in the IDE, plus the AI tools that matter for game development: asset generation (Fal, Scenario, Layer), Blender via MCP, and engine integrations.

## Format

- **12 weeks, about 6 to 8 hours a week.** That's deliberately below 10 hours a week, so working developers finish.
- **Each week has 4 lessons of 60 to 90 minutes**: a hook, the concept, a guided exercise, a checkpoint and an optional side quest. There is also **one weekly build lab of 2 to 3 hours**, framed as the "boss delivery."
- **One shared game runs through the whole course** (Goblin Express; see `03-shared-game-brief.md`). Optional side quests let learners apply each lesson to a game of their own.
- **Ship something in Week 1.** A playable game in the browser by the end of Day 1.
- **Web first, engines second.** The browser gives the agent the tightest loop: it can write code, run it, screenshot it and fix it. Those habits then transfer to engines.
- **One shared path for programmers and artists**, with branch exercises in the labs, rather than two separate courses.
- **Tool churn is expected.** Each lesson separates durable concepts from tool walkthroughs, and walkthroughs show a "last verified" date.

## Prerequisites

- A paid Claude plan (Pro or higher) or an Anthropic Console account with API billing. State this up front. A lesson on managing usage and cost is planned.
- A Mac on macOS 13 or later, or a 64-bit PC on Windows 10 version 1809 or later. No Node.js required for Claude Code's native installer.
- Prior game-development experience. No AI experience needed.

## Tone

The course should be fun to go through, like playing a game: humor, images, animation and motion graphics where they help, plus light gamification with achievements and a world map. Don't overdo it. See `04-lesson-template.md` for the voice rules.
